# my_soap_fps_project
This repository provides an automated, physics-informed pipeline to prune redundant atomic configurations from dataset files formatted for Machine Learning Potentials. Combining SOAP descriptors with a species-aware Farthest Point Sampling (FPS) strategy, it eliminates repetitive structures, while retaining chemically distinct atomic environments.
In this pipeline PCA is incorporated for visualization of the datapoints before and after filtration.
